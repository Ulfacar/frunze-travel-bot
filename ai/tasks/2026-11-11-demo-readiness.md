## 🔴 Дыра 1: учёток daulet и marsel нет вовсе

На проде семь логинов: `admin`, `ademi`, `medina`, `eliza`, `grisha`, `aisina`,
`grisha-admin`. Даулета и Марселя нет, хотя их скоупы ботов в коде заведены ещё
05.11 (`manager_scope.BOT_SCOPE_BY_MANAGER`) — то есть всё готово, кроме самих учёток.

Решается запуском на сервере:

    cd /root/frunze-travel
    python3 scripts/add_manager_accounts.py daulet:Даулет marsel:Марсель
    docker compose -f docker-compose.yml -f docker-compose.vps.yml --env-file prod.env up -d app

Скрипт добавляет только недостающих, существующие учётки не трогает, делает копию
`prod.env` и кладёт пароли в файл `new-logins-<дата>.json` рядом с правами 0600.
Рестарт обязателен: `MANAGERS` читается при старте.

**Запускает Алан.** Агент в `prod.env` не пишет: это файл с паролями всех менеджеров.

## 🔴 Дыра 2: заявок на проде НОЛЬ, и визовых воронок нет

    заявок всего: 0
    visa_schengen  — воронки нет, заявку завести нельзя
    visa_china / visa_korea / visa_japan / visa_italy — воронки нет
    air_ticket / hotel_booking — воронки нет

То есть вся часть «после договора» на демонстрации будет пустой: нажать «Договор
подписан → создать услугу» по шенгену не получится, механизм ответит «product has no
current published workflow version».

Шенгенский черновик **готов и лежит в образе** (14 рабочих этапов, пересобран по
ответам Медины), но на боевую CRM не публиковался. Публикация — отдельное действие:

    python3 scripts/publish_kg_visa_funnel.py --funnel schengen --yes --dsn "<боевой DSN>"

Это запись в прод-базу (новая `WorkflowVersion`), поэтому только по слову Алана.
Обратимость: версии процессов версионируются, новая публикация не ломает старые
заявки — а заявок сейчас и нет вовсе.

Открытыми остаются два вопроса Медине (собеседование по шенгену; подготовка одной
стадией). Публиковать до её ответа можно — следующая версия выпускается поверх.

## 🔴 Дыра 3: сводка пилота не видна никому

`panel_pilot_summary_enabled = False`, `PANEL_DIRECTION_LEADS` пуст. По ответу
заказчика 2.4 сводку должны видеть Гриша, Даулет и Марсель. Нужны обе правки: флаг и
список руководителей по направлениям в `prod.env`. Напомню ограничение из разбора
05.11: доступ требует ОДНОВРЕМЕННО скоупа ботов и записи в `PANEL_DIRECTION_LEADS`,
поэтому каждый увидит сводку только своего направления (`app/admin/pilot_summary.py`).
