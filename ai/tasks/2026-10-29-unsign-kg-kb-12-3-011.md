# Снятие подписи с KG.KB.12.3#011 — льгота швейной отрасли истекает 01.11.2026

Статус: **ПОДГОТОВЛЕНО, НЕ ПРИМЕНЕНО.** Ждём слова Гриши или Алана.
Класс риска: **C** — данные знаний, которые бот произносит клиенту как норму закона.
Поставлена 29.10.2026 по просьбе Алана (пункт 6 перепроверки).

## Почему

Подписанный кусок, который бот сегодня произносит клиенту дословно:

> **Льготная сетка для швейной отрасли** (п.2-1 ПКМ № 312 в ред. ПКМ № 506) действует
> **до 01.11.2026**; нужно письмо ТПП КР, подтверждающее членство. Для B2B-клиентов-швейников
> — обязательно запросить письмо ТПП и в конце октября 2026 проверить, продлена ли льгота
> (приложение Г, п.23).

Срок истекает **1 ноября 2026**, то есть через три дня. Сам текст ТЗ требует «в конце
октября проверить, продлена ли льгота» — и этот момент наступил. С 01.11 кусок становится
утверждением о норме, срок действия которой истёк, и бот будет врать B2B-клиенту о
стоимости оформления Единого разрешения.

Проверено, что это **единственный** подписанный кусок со сроком 01.11.2026: по 454
подписям восстановлены тексты из корпуса и прогнан поиск по `01.11.2026 | 1 ноября 2026`.
Таблица тарифов 12.3 с той же датой в шапке **не подписана** — её отсеяло правило «есть
суммы», так что отдельного действия она не требует.

## Что именно меняется

Один объект удаляется из массива `approved` в `knowledge/kg_entry/answers-approved-v1.1.yaml`
(файл JSON, несмотря на расширение). Кода не касаемся: оверлей — дата-дифф ровно для того,
чтобы в ревью были видны те строки, из-за которых бот начал что-то утверждать.

```json
{
  "piece_id": "KG.KB.12.3#011",
  "text_sha256": "cce244dd25e0d130bcc39418e78b9feb810d155711e9c8bcfe1cb405c7d2bd63",
  "block": 12,
  "section": "12.3",
  "pdf_pages": [56, 57],
  "basis": "отбор по правилу scripts/build_answers_approval.py: ...",
  "approved_by": "Алан (владелец проекта), 22.10.2026: «грузи» ...",
  "checked_by": "tests/test_answers_index.py + scripts/run_entry_stories.py",
  "approved_at": "2026-10-23"
}
```

Подписей станет **453 вместо 454**. `corpus_hash` и `source_hash` не трогаем: корпус и
исходный PDF не менялись, меняется только разрешение произносить.

## Что увидит клиент

Кусок перестаёт быть произносимым, и по механике `app/knowledge/answers_approval.py` бот
на вопрос швейника отвечает «уточнит специалист» и передаёт человеку — это штатное
поведение до приёмки, решение владельца от 22.10. Молчание здесь честнее: льгота либо
продлена (тогда нужен новый текст и новая подпись), либо нет (тогда работает общая
ставка, которая в ТЗ помечена `[ПРОВЕРИТЬ]` и никем не подтверждена).

## Доказательство, что снятие делает именно это

Симуляция 29.10 на подготовленном файле, вызовом боевой функции `answers_approval.approved`:

```
        сейчас: подписей 454, бот может произнести кусок = True
  после снятия: подписей 453, бот может произнести кусок = False
```

## Как применить, когда будет слово

```bash
python - <<'PY'
import json, re
from pathlib import Path
p = Path('knowledge/kg_entry/answers-approved-v1.1.yaml')
raw = p.read_text('utf-8')
m = re.search(r'\n(\s*)\{\n\s*"piece_id": "KG\.KB\.12\.3#011",.*?\n\s*\},', raw, re.S)
assert m, 'блок не найден — файл уже менялся, разбираться руками'
patched = raw[:m.start()] + raw[m.end():]
doc = json.loads(patched)
assert len(doc['approved']) == 453 and not any(
    r['piece_id'] == 'KG.KB.12.3#011' for r in doc['approved'])
p.write_text(patched, 'utf-8')
PY
python -m pytest tests/test_answers_index.py tests/test_entry_knowledge_tool.py -q -p no:randomly
```

Форма файла сохраняется один в один — удаляются ровно эти строки, без переформатирования
остальных 453 подписей.

## Откат

`git checkout -- knowledge/kg_entry/answers-approved-v1.1.yaml`. Подпись — данные в git,
отдельного бэкапа не требует. Если льгота продлена, возвращать нужно **не старый кусок**, а
новый текст с новым сроком и новой подписью: `text_sha256` защищает именно от этого — правка
текста аннулирует одобрение сама.

## Чего это НЕ делает

- не касается прода: оверлей читается из образа, значит нужен деплой, а деплой — отдельное
  слово Алана;
- не отвечает на вопрос, продлена ли льгота. Это вопрос к Грише, и ответ на него решает,
  снимаем мы подпись или заменяем текст;
- не трогает остальные 453 подписи и не меняет корпус.

## Решение, которое нужно от человека

1. **Гриша:** продлена ли льготная сетка для швейной отрасли после 01.11.2026?
   - продлена → нужен новый текст куска с новым сроком и новая подпись;
   - не продлена или неизвестно → снимаем подпись по этой задаче.
2. **Алан:** применять ли снятие сейчас, до ответа Гриши. Срок истекает 01.11, и до ответа
   бот три дня будет называть льготу действующей.
