# E5-02D — поиск страны в черновых правилах

Локальный индекс ссылок для проверки знаний. Для ISO3 или явного алиаса возвращает связанные
единицы конкретной версии, их значения/статусы/источники и незакрытые вопросы. При каждом
запросе используются готовые списки ссылок; JSON всех единиц заново не сканируется.

`app/knowledge/country_index.py` — `CountryRuleIndex(meta, countries, units, source_hash=...)`.
Конструктор заново проверяет schema/semantics/source_hash через существующий preflight,
сохраняет собственный снимок; `lookup()` и `summary()` возвращают отделённые копии.
Вызывающая сторона должна передать хеш фактически прочитанного источника. CLI делает это
сам через `preflight_bundle`, проверяет PDF, затем строит индекс. Сам Python API файлы не читает.

```powershell
python -X utf8 scripts/review_kg_country.py knowledge/kg_entry/draft-v1.1 --source "..\Kyrgyzstan-visa-knowledge-base-v1.1.pdf" --summary
python -X utf8 scripts/review_kg_country.py knowledge/kg_entry/draft-v1.1 --source "..\Kyrgyzstan-visa-knowledge-base-v1.1.pdf" --country Молдова
python -X utf8 scripts/review_kg_country.py knowledge/kg_entry/draft-v1.1 --source "..\Kyrgyzstan-visa-knowledge-base-v1.1.pdf" --country RUS --document-type diplomatic
python -m pytest tests/test_kg_country_index.py -q
```

CLI выводит JSON, не создаёт файлы/БД, не читает `.env`, не вызывает сеть/LLM.
Код выхода 0 означает успешную проверку/поиск, включая `status=unknown_country`; 1 —
ошибка источника/индекса. Ошибки не содержат исходного значения запроса.
Нормализация совпадает с bundle: NFKC, casefold, схлопывание пробелов. Нет fuzzy-match,
догадок по похожим буквам, неявного ISO2 или загрузки новых алиасов. Например, реальный
bundle знает `Россия` и `RUS`; английские названия поддерживаются только если явно внесены
в справочник конкретной версии. Неизвестное название не превращается в общий порядок въезда.

## Что именно индексируется

| Источник связи | Результат |
|---|---|
| `value.countries` в VF/VR | Ссылки на все кандидаты без выбора приоритета |
| `special_regime.value.applies_to.countries` | Ссылка с сохранёнными условиями |
| Special без country filter | Отдельный `country_independent`, не автоматическая применимость |
| `KG.REG.EXEMPT.<ISO3>` / `KG.REG.TERM.<ISO3>` | Отдельные категории освобождения и срока регистрации, включая NULL/blocked |
| `registration_default.value.not_in_list` | Только явно перечисленные страны, не остаток всего справочника |
| `countries: all_others` | Отдельный `source_fallbacks`, не выбранный режим |
| NULL value + `blocked_value.country_iso3` или `candidate.countries` | Только evidence-only ссылка; рабочее value остаётся NULL |
| Остальные country-related units без структурированной привязки | Явный `unmapped_country_rules` в результате и summary |

Все structured hints проверяются по справочнику, дубли и противоречащие друг другу поля
отклоняются. Текст и похожие на ISO суффиксы VF/SP ID не используются для угадывания страны.
Отсутствие условного правила не подменяется разрешением общего режима.

Результат для реального bundle v1.1: **249 кодов / 365 алиасов**, **114 country-related
units** из 208, **201 ссылка для 110 стран**, из них 16 evidence-only. Остальные 94 единицы
(цены, шаблоны, сроки и т.д.) не относятся к этому индексу. `KG.VR.GENERAL` — одна отдельная
fallback-ссылка. Пять единиц пока без машинной привязки: четыре `KG.SP.*` и `KG.VF.GCC`;
это существующие пробелы схемы/источника, а не потерянные записи. Ни одна из 114 не confirmed.

Молдова сохраняет отдельно безвизовый draft, заблокированное освобождение SRC-04 с NULL
и срок оформления регистрации. Греция и Чили сохраняют собственные сроки освобождения,
не значение всей безвизовой группы. Эти примеры описывают структуру данных, не консультацию.

## Границы и проверка

Всегда `review_only`, `may_quote=false`, `publication_approved=false`,
`applicability_evaluated=false`, `selected_regime=null`. `document_type` сохраняется;
необычный документ добавляет `document_review_required`. Ссылки по гражданству сами по
себе не доказывают применимость к дипломатическому/служебному паспорту или удостоверению ООН.
Даже synthetic confirmed единица не получает разрешения на выдачу через этот интерфейс.

Это **не реализация таблицы `entry_country_rules`** из архитектурного проекта. Материализация
при импорте, выбор режима по документу/условиям, проверка даты/допуска, публикация/CAS/откат
и подключение к боту остаются впереди. Новых миграций и изменений существующего импорта нет.

Финальный связанный прогон: **299 passed, 37.80s**, включая **42 новых теста**, Windows /
Python 3.12, 07.10.2026. Проверены реальные исключения, неполные данные, неизвестные страны,
несколько кандидатов, повреждённые hints, изоляция снимка/ответов, повтор CLI без изменения
исходных файлов и неверный PDF. SELF_REVIEW: `ai/reviews/2026-10-07-e5-02d-country-self-review.md`.
Коммит и проверка его копии — в актуальном `ai/STATE.md` и handoff.
