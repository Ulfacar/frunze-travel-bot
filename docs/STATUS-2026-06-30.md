## 2. Что УЖЕ задеплоено и проверено на проде ✅
- **Возрасты детей:** TourVisor требует `childage1..N`; без них поиск с детьми = 0 отелей.
  Фикс: `_parse_tourists` достаёт возрасты (текст/поле `children_ages`), `_build_query` шлёт
  `childage*`, дефолт 7, макс 4. Проверено: Турция 2 взр+3 детей → 5 отелей.
- **Курорт + питание:** без них поиск отдавал «только Стамбул». Фикс: `resolve_regions`
  (`regions`) + `_parse_meal` (`meal`), поля `region`/`meal` в инструменте, правило в промпте.
  Проверено: Анталья + всё включено → 5 отелей 4–5★ AI/UAI.
- **Визовый гейтинг по странам:** по «нашим» странам (`GETVISA_VISA_SCOPE`: США, Канада, Шенген,
  Британия, Китай, Таиланд, Япония, Корея, ОАЭ) бот ведёт сам ПОЗИТИВНО без гарантий; по чужим
  (Бразилия и т.п.) — сразу `handoff_to_manager`. Правило в `app/agent/prompts/visa.py`.
- **Дата-фикс (ЗАДЕПЛОЕНО 30.06 15:20):** LLM ставил прошлый год → TourVisor `dateto - bad format`
  → «Поиск временно недоступен». Правка в `_parse_dates`: прошлая дата переносится на ближайший
  будущий год. Проверено вживую на проде: `05.08.2025` больше не валит поиск.
- **Бюджетный P0 (ЗАДЕПЛОЕНО 30.06 15:20):** низкий бюджет → 0 отелей → тупик. Теперь в `search()`:
  при пустой выдаче с `priceto` — один повторный проход БЕЗ ценового потолка; если есть варианты
  выше бюджета — `_format_over_budget` показывает 2–3 самых дешёвых + честная мин. цена (валюта из
  выдачи), агент подаёт тёпло. Проверено: Египет 2+2 AI, бюджет 2000$ → честно «от 3535 USD» + 3
  отеля, а не «не нашлось». Хелперы `_hotel_price`/`_format_over_budget`, правило в `tours.py`.
  Тесты: `tests/test_tourvisor_client.py`, всего 149 зелёных. Реализация Codex, ревью+деплой Claude.
