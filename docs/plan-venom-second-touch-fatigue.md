**Дата:** 13.07.2026 · Ветка: feature/token-economy-phase1
**Источник идей:** разбор бота-конкурента Nextbot (их дожим «кейс/гарантия/страх» + провал их бота на бесконечных вопросах).
**Роли:** Claude — план/ревью, Codex — код. Ревью через `codex-reviewer` (Opus).

Продолжение коммита `0bc2a96` (дожим + ценовая вилка). Две дешёвые фичи в одну итерацию.

## #1 — Второе касание дожима с ответом на страх/возражение

**Проблема:** `followup.py._send_followups` зовёт `followup_ping_for(funnel, post_consult)` БЕЗ счётчика → 1-й и 2-й пинг текстово одинаковы («вы ещё думаете?»). `followup_max_pings=2` уже позволяет 2 касания — нужен просто другой текст для второго.

**Решение:** сделать пинг счётчик-зависимым. Второй пинг снимает конкретный страх воронки и ведёт в офис/к менеджеру. Третьего нет (стоп по `followup_max_pings`, как у Nextbot «не спам-радио»).

**Изменения:**
1. `app/core/branding.py`:
   - Новый dict `FOLLOWUP_PINGS_SECOND` (visa/tours/tickets) + `_FOLLOWUP_SECOND_DEFAULT`.
   - `followup_ping_for(funnel, *, post_consult=False, count=0)` — если `count >= 1`, вернуть
     `FOLLOWUP_PINGS_SECOND` (перебивает post_consult); иначе прежнее поведение.
     `count` по умолчанию 0 → обратная совместимость, старые вызовы/тесты не ломаются.
2. `app/core/followup.py`:
   - В `_send_followups` передать `count=followup_pings(c)` в `followup_ping_for(...)`.
     (На 1-м отправлении `followup_pings==0` → count=0; на 2-м `==1` → count=1.)

**Тексты 2-го касания** (стиль Frunze: коротко, 1 эмодзи, без markdown, БЕЗ обещания скидок):
- **visa** (страх «а вдруг откажут»): «Понимаю, виза — это всегда про «а вдруг откажут». У нас при отказе вторую попытку делаем бесплатно, а анкету готовим так, чтобы повысить шансы. Давайте разберём ваш случай 🙏» *(факт «вторая попытка бесплатно» уже в knowledge.py — разрешён)*
- **tours** (возражение по цене): «По цене живой менеджер отработает лучше — подберёт под ваш бюджет выгоднее, чем в поиске. Покажу пару вариантов, ни к чему не обязывает 🙏»
- **tickets** (промедление): «Цены на билеты быстро меняются — чтобы не упустить удобный рейс, менеджер зафиксирует лучшую цену под ваши даты. Подскажете маршрут? ✈️»
- **default:** «Если остались сомнения — давайте обсудим, менеджер поможет подобрать оптимально под вашу ситуацию 🙏»

**Гейт:** отдельный флаг НЕ нужен — второе касание срабатывает только когда работает сам дожим
(авто-флаг `followup_enabled`, сейчас OFF, или кнопка ручного дожима `run_manual`).

## #2 — Режим «усталость от вопросов → суть без анкеты»

**Проблема:** бот может задалбывать вопросами (на чём сел бот Nextbot: клиент «хватит спрашивать/наскучил» — а тот всё равно «①②③ какой канал?»). У нас есть анти-цикл и анти-троллинг (→ handoff), но НЕТ отдельного правила «клиент устал именно от расспросов».

**Решение:** guardrail-инструкция в `app/agent/prompts/common.py` → `LANGUAGE_AND_ESCALATION`
(always-on, рядом с существующими анти-цикл/анти-троллинг — та же категория). При сигналах
усталости от вопросов — НЕ задавать новый вопрос, дать краткий итог + один шаг. Это НЕ handoff
(клиент вовлечён, просто устал), а «перестань допрашивать, дай суть».

**Текст (добавить в LANGUAGE_AND_ESCALATION):**
```
УСТАЛОСТЬ ОТ ВОПРОСОВ: если клиент раздражён именно расспросами («хватит спрашивать»,
«надоело», «наскучил», «не задавай вопросы», «хватит вопросов», «задолбал») — НЕ задавай
новый вопрос. Коротко подведи итог: что можешь предложить по его запросу и один конкретный
следующий шаг (в офис / к менеджеру / подбор). Верни инициативу клиенту без анкеты. Это не
повод передавать менеджеру — просто перестань допрашивать и дай суть.
```

**Почему always-on, а не под флагом:** это защитный guardrail (выключить = «бот продолжает
допрашивать раздражённого клиента», чего никогда не хочется), в отличие от стратегического
дожима (`dozhim_enabled`), который A/B-тестируем. Разные категории. Идёт в прод на следующем
деплое (деплой Алан контролирует отдельно, коммит прод не трогает).

## Тесты
- `followup_ping_for(funnel, count=0)` == прежний текст; `count=1` → текст из `FOLLOWUP_PINGS_SECOND`.
- `count>=1` перебивает `post_consult`.
- `_send_followups`: на 2-м пинге (followup_pings==1) уходит второй текст (мок outbound/store).
- `LANGUAGE_AND_ESCALATION` содержит блок «УСТАЛОСТЬ ОТ ВОПРОСОВ» (и он попадает во все воронки).
- Существующие followup/prompt-тесты зелёные.

## Приёмка
- Обратная совместимость: `count` по умолчанию 0 — регрессов в существующих вызовах нет.
- Тексты без скидок; visa-факт «вторая попытка бесплатно» соответствует knowledge.py.
- `codex-reviewer` без критичных находок; весь набор тестов зелёный.
