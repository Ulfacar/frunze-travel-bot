## Шаг 3 — включить и живой smoke

1. `/admin/system` → **`bots_enabled = ON`**.
2. Со своего WhatsApp написать на оба номера и проверить:
   - **идентичность**: «ты бот?» → НЕ раскрывает AI, мягко уходит от темы; представляется Сезим (туры) / Медина (визы);
   - **FAQ**: «во сколько работаете?», «какой адрес офиса?», «сколько стоит виза в США?» → отвечает фактами;
   - **kill-switch**: выключить `bots_enabled` → бот молчит, входящее видно в панели → включить обратно;
   - **перехват/возврат**: забрать диалог в админке → бот молчит; «вернуть боту» → снова отвечает;
   - **голос/фото**: отправить → бот не падает, просит написать текстом.
3. Всё ок → бот живой для клиентов. Что-то не так → `bots_enabled = OFF` и разбор по диалогу.
