# ТЗ: подборка туров карточками + страница «Подробнее здесь»

Веном v2, фаза 1. Гейт — `tests/test_tour_cards.py` и `tests/test_tour_cards_flow.py`,
написаны ДО кода и исполнителем не редактируются.

## Зачем (со встречи 11.08 и с замеров)

Менеджеры-люди отправляют клиенту подборку из 8 карточек и ссылку, по которой клиент сам
листает варианты. Бот присылает **один отель одной строкой**. Дословно со встречи: «Блин,
почему только один он показывает?».

Причина не в TourVisor:

* `client.py:632` обрезает выдачу до 5 отелей, и эти 5 строк уходят НЕ клиенту, а модели;
* общий промпт `prompts/common.py:9-12` требует «1–2 фразы, максимум ~300 знаков, БЕЗ
  markdown, без списков и эмодзи» — в 300 знаков влезает ровно один отель;
* валидатор дополнительно срезает буллеты и жирный (`validator.py:34,135`);
* итоговый текст клиенту целиком сочиняет модель (`runner.py:185`) — кода, который отправлял
  бы подборку, в проекте нет.

## Разведка 11.08 (`scripts/tourvisor_probe.py`, прогон на проде)

Запрос Бишкек → Турция, Аланья, 17–25.08, 2 взр + дети 7 и 12, AI, 5*: `hotelsfound=55`,
вернулось 25 отелей и 95 туров. **Заполненность 100% по всем полям ниже:**

| Уровень | Поля |
|---|---|
| тур | `room` («standard room land view»), `placement` («TRPL + 1 CHD»), `adults`, `child`, `flydate`, `nights`, `mealrussian` («AI - Все Включено»), `price`, `currency` (EUR), `tourid`, `operatorname`, `tourname` |
| отель | `hotelname`, `hotelstars`, `hotelcode`, `hotelrating` (3.5), `picturelink` (`https://static.tourvisor.ru/hotel_pics/main400/1188.jpg`), `hoteldescription`, `seadistance` (50), `countryname`, `regionname`, `fulldesclink`, `reviewlink` |

Из этого следует три вещи:

1. Тип номера и состав **есть в ответе** — гадать из запроса не нужно.
2. Фото и описание отеля есть — страница подборки будет с картинками.
3. **`tvcard`/`tourcart` в ответе нет ни одного вхождения** — ссылку подборки TourVisor
   программно не собрать. Это проверено, а не предположено. Значит ссылку делаем свою.

Отдельная находка, чинится тем же заходом: на «7 ночей» в запрос ушло
`nightsfrom/nightsto = 8` — бот ищет не то, что просит клиент.

## Границы — чего НЕ делаем

* **Не трогаем `prompts/common.py`** и остальной диалог: он остаётся живым текстом модели.
* **Не трогаем `_SAFE_URL_PREFIXES`** — модель по-прежнему не имеет права выдумать ни один
  URL. Ссылку добавляет только код.
* **Не разбиваем ход на два сообщения** — дедуп `mark_own`, лог панели и пуш менеджеру
  завязаны на один `reply`.
* Не делаем сигнал менеджеру «клиент открыл подборку» — следующим заходом.
* Не мигрируем на новый REST API TourVisor.
* Рабочие визы (блок C плана) — отдельное ТЗ и отдельный гейт.

## Точки врезки

1. **`app/integrations/tourvisor/cards.py`** — новый модуль, чистый рендер без сети. Отдельно
   от `client.py`, потому что формат — это то, что будет меняться по вкусу владельца, а
   транспорт — нет.
2. **`app/integrations/tourvisor/client.py`** — читать `room`/`placement`/`adults`/`child`/
   `tourid`/`hotelcode`/`picturelink`/`hotelrating`/`seadistance`/`hoteldescription`;
   `TourSearch.cards` и `TourSearch.offer` (структурные данные для страницы); проброс `limit`.
3. **`app/agent/runner.py`** — врезка в `run_turn` **после `validate_reply`**: карточки
   физически не проходят через `strip_markdown`, поэтому `*жирный*` WhatsApp и эмодзи
   доезжают до клиента целыми. Транспорт — `DialogState.pending_tour_cards`, чистится на
   входе `run_tours_turn` (иначе упавший ход приклеит карточки к следующей реплике).
4. **`app/web/offers.py`** (новый) — публичный роут `GET /t/{slug}`, страница подборки.
   Вне авторизации админки, slug неугадываемый (16 символов).
5. **`app/config.py` + `docker-compose.yml` + `app/admin/router.py`** — флаг
   `tours_cards_enabled`, дефолт **false** = нынешнее поведение.

## Формат карточки (эталон — шаблон менеджеров)

```
🏠 *THE NORA HOTELS FAMILY CLUB 5⭐️*
✈️ Бишкек ➡️ Турция, Аланья
📅 17 авг, 🌙 6нч
🛌 economy pool room, 2взр 2реб
🍽️ Все Включено
🏷️ 2 364 eur
```

Правила:

* состав берём **из тура** (`adults`/`child`), а не из запроса клиента: TourVisor сам решает
  размещение — на запрос «2 взрослых + дети 7 и 12» реально пришло `adults=3, child=1`
  (12-летний считается взрослым). У менеджеров в шаблоне ровно так же — «3взр 1реб»;
* питание: `mealrussian` = «AI - Все Включено» → печатаем «Все Включено» (префикс кода режем);
* нет поля → строки нет. Никаких «🍽️ —» и никаких выдумок;
* нет цены или валюты → отель выбрасывается целиком: цена без валюты в Бишкеке читается как
  сомы, и это дороже, чем показать на один отель меньше;
* цена `2364` → `2 364`, валюта в нижнем регистре («eur»), как у менеджеров; значение — ровно
  то, что отдал TourVisor, без пересчёта;
* дата `17.08.2026` → «17 авг»; не распарсилось — печатаем как есть;
* имя отеля санитизируется от `*`, `_`, `~`, `` ` `` и переводов строк — иначе одна звёздочка
  в названии превратит пол-сообщения в жирный;
* сортировка по цене, дедуп по имени отеля, лимит `TOUR_CARDS_LIMIT = 5` (решение владельца);
* пометки бюджета («в бюджет», «выше бюджета на 20%») в карточку НЕ идут — их нет у
  менеджеров; про бюджет говорит подводка модели.

Хвост сообщения:

```
Подробнее здесь:
https://frunzetravel.kg/t/<slug>
```

## Страница подборки `/t/{slug}`

Своя, а не `tourcart.ru`: их ссылку из шлюза не собрать (см. разведку), а своя ведёт в нашу
воронку и не уводит оплаченного рекламой клиента к конкурентам — ровно та причина, по которой
03.08 убрали гугл-ссылки.

* хранение: таблица `tour_offers` (slug PK, conv_key, bot_id, created_at, payload JSON);
* содержимое карточки на странице: фото (`picturelink`), название, звёзды, рейтинг, курорт,
  расстояние до моря, описание, даты/ночи/питание/номер/состав, цена, оператор;
* кнопка «Написать менеджеру» → `wa.me` номера того канала, где идёт диалог;
* стиль — токены макета календаря (тил `#0E5C57` / оранж `#DB7526`), светлая и тёмная тема,
  телефон в первую очередь;
* страница не индексируется (`noindex`), slug неугадываемый, никаких персональных данных
  клиента на ней нет — только туры.

## Гейт

`tests/test_tour_cards.py` — рендер:

1. полный тур → карточка совпадает с эталоном посимвольно;
2. нет `room` → `🛌 2взр 2реб`, ничего не выдумано;
3. нет `room` и нет состава → строки `🛌` нет;
4. нет питания → нет пустого `🍽️`;
5. **ложноположительный:** нет цены ИЛИ нет валюты → отель в подборку не попал;
6. `2364` / `"2 364"` / `2364.0` → `2 364`; мусор → отель выброшен;
7. 12 отелей → 5 карточек; 3 → 3; 0 → пустой список;
8. сортировка по цене, дедуп по имени;

10. `mealrussian` «AI - Все Включено» → «Все Включено»; «Все Включено» → без изменений;
11. `17.08.2026` → «17 авг», `01.09.2026` → «1 сен», мусор → как есть;
12. состав: `adults=2, child=0` → «2взр»; `adults=3, child=1` → «3взр 1реб»;
13. между карточками ровно одна пустая строка; ни одна строка не начинается с `-`/`*`/`•`.
