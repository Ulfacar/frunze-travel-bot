## 🟢 ЧТО СДЕЛАНО

### 1. Макет календаря звонков (визуал)
`docs/calendar-mockup.html` — открыть двойным кликом. 3 кликабельных экрана:
- **Экран менеджера утром** — стопка звонков + досье (клик по звонку → досье справа)
- **Сетка недели** — время × колонки менеджеров, загрузка, «сейчас»
- **Выбор слота в WhatsApp** — переписка, клиент отвечает цифрой

Кнопка ◐ вверху = светлая/тёмная тема. Это МАКЕТ (как будет выглядеть), не рабочий код.
→ Договорились: этот стиль станет эталоном для будущего редизайна всей админки.

### 2. Дожим + ценовая вилка (код, коммит `0bc2a96`)
Бот доводит тёплого клиента до офиса и отрабатывает возражение по цене
(**без обещания скидок**): туры — подберём под бюджет; визы — консультация эксперта;
«по цене живой менеджер отработает лучше → в офис».
- Флаг **`dozhim_enabled`, дефолт OFF** — на проде ничего не изменится, пока не включишь.

### 3. Второе касание + режим усталости (код, коммит `a4edd5a`)
Идеи с разбора бота-конкурента **Nextbot**:
- **2-е касание дожима**: если лид замолчал, второй пинг снимает страх воронки
  (визы — «откажут → 2-я попытка бесплатно», туры — цена, билеты — цены меняются), потом стоп.
- **Режим «усталость→суть»**: клиент «хватит спрашивать/наскучил» → бот бросает вопросы,
  даёт суть + один шаг. Лечит ровно то, на чём бот Nextbot сел в лужу.

**Всё отревьюено codex-reviewer (Opus) — без критичных находок. 335 тестов зелёные.**
