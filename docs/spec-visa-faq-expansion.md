## Цель
Перевести «обычные вопросы» виза-бота на детерминированный FAQ-слой (0 токенов LLM). Источник ответов — `docs/visa-faq-questionnaire-filled-draft-2026-07-02.md` (подтверждено менеджерами). Реализация — добавление правил в `seed_defaults()` в `app/core/faq.py`.

## Project gotchas (обязательно учесть)
1. **`visa_pricing.py` перехватывает раньше FAQ.** Для visa-воронки сообщения с ценовыми словами (`PRICE_INTENT_RE`: `сколько|цена|стоимост|прайс|почем|оплат|сбор|price|cost`) и self-visa обрабатываются в `app/core/visa_pricing.py` ДО FAQ-стора. → Паттерны новых правил НЕ должны содержать эти подстроки. Особенно избегать `оплат` (есть в «предоплата», «оплатить»). Цены стран НЕ трогаем — они уже в `_COUNTRY_PRICES`.
2. **Ничья приоритетов → пустой ответ.** `match_faq` возвращает `None`, если два сматчившихся правила имеют равный `priority`. Приоритеты новых правил заданы ниже уникальными и не пересекаются по паттернам с существующими (25/30/35). Не менять их.
3. **Скоуп воронки.** Все новые правила `funnel="visa"` — не сработают в tours/tickets. НЕ ставить `funnel=None`.
4. **Идемпотентность.** `seed_defaults()` апсертит по `(funnel, title)`; ручные правки менеджера не трогаются. Просто добавить новые словари в список `defaults`.
5. Ответы визы: только официальный прайс, без гарантий одобрения; по «чужим» странам — к менеджеру; не упоминать рабочие визы в списке услуг.
