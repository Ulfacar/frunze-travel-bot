# Аналоги на рынке — как такие боты работают у других

**Дата:** 18.06.2026. Цель — не копировать код, а понять проверенную механику, чтобы
не изобретать велосипед. Ниже — реальные продукты и что из их подхода брать.

---

## 1. Telegram-бот самого TourVisor (прямой аналог, тот же API-провайдер)

У TourVisor **есть готовый модуль Telegram-бота** для турагентств. Это эталон flow подбора.

**Шаги диалога (их проверенный набор вопросов):**
1. «Найти тур»
2. Город отправления
3. Страна назначения
4. Состав туристов
5. Звёздность отеля
6. Тип питания
7. Продолжительность и даты
8. → запрос **номера телефона** → выдаёт **ссылку на результаты поиска** на сайте агентства

**Плюс:** подписка на горящие туры, рассылки по направлениям, отслеживание цен.
**Условие:** требуется установленный модуль поиска TourVisor на сайте агентства.

**Вывод для нас:**
- ✅ **Берём их набор квалификационных вопросов** почти как есть — это UX от владельца API
  (обновим наш список полей: добавить *звёздность* и *питание*).
- ⚠️ Их бот — кнопочный и просто отдаёт ссылку на сайт + меняет результаты на телефон.
  **Наше отличие:** живой AI-диалог, оценка/ветвление, дожим в офис, виза, канбан Bitrix.
- 💡 Стоит спросить заказчика: есть ли у Frunze Travel модуль поиска TourVisor на сайте —
  тогда часть (горящие туры/подписки) можно не строить, а переиспользовать.

## 2. aitouragent.ru — AI travel bot (ближайший AI-аналог)

**Механика:**
- Спрашивает страну/курорт/отель → дату вылета → кол-во ночей → состав туристов → **бюджет**.
- **Логика подбора:** сначала отели с наивысшим рейтингом **в пределах бюджета**; если бюджет
  превышен — лучшие доступные варианты по качеству.
- Каналы: виджет на сайте + мессенджеры (VK, Telegram, WhatsApp).
- **Передача менеджеру:** автоматически формирует заявку с полными данными подобранного тура
  и контактами клиента.

**Вывод для нас:**
- ✅ **Берём логику сортировки по бюджету** (в пределах бюджета → по рейтингу; иначе ближайшее).
- ✅ Подтверждает наш принцип «собрать данные → заявка менеджеру с полным контекстом».

## 3. Bitrix24 для туризма — воронки и канбан (для фазы 2)

Из практики настройки Bitrix24 под турагентства:
- **Туннель между воронками** «Продажа» и «Виза»: переход из стадии «В работе» →
  «Виза нужна». То есть наши воронки Туры и Визы связаны переходом — учтём при моделировании.
- Воронка «Привлечение клиентов»: **Генерация лидов → Контакт → Консультация и
  предложение туров → Заключение договора**.

**Вывод для нас:**
- ✅ Готовый ориентир стадий канбана для `crm_update_stage` (фаза 2).
- ✅ Идея «туннеля» Туры↔Визы — если у клиента всплывает виза, сделка перетекает в визовую воронку.

## 4. Готовые «ИИ-агенты для Bitrix24» (рыночная валидация модели)

Сервисы подключают AI-чат-бота к Bitrix24: ответ за ~15 сек 24/7, менеджеры получают
квалифицированных лидов с заполненными карточками, конверсия в сделку +15–30%.
Отдельные сервисы AI-квалификации работают как **фильтр** между входящим потоком и
отделом продаж: нецелевые/спам-лиды не попадают в активную воронку.

**Вывод для нас:**
- ✅ Подтверждает бизнес-ценность (скорость ответа + квалификация = рост конверсии).
- 💡 Концепция «фильтра» полезна для определения **«проблемного клиента»**: бот может
  маркировать нецелевые/сложные обращения и не пускать их сразу к менеджеру, а звать в офис.

## Итог: что переиспользуем, что строим сами

| Берём готовое/проверенное | Строим сами (наша ценность) |
|---------------------------|------------------------------|
| Набор вопросов подбора тура от TourVisor | Живой **AI-диалог** вместо кнопочного дерева |
| Логика сортировки по бюджету (aitouragent) | **Визовая воронка + оценка шанса в %** |
| Стадии канбана и туннель Туры↔Визы (Bitrix24) | Маршрутизация **«проблемный клиент → офис»** |
| Модель «AI как фильтр перед отделом продаж» | Мульти-канал через Bitrix24 Открытые линии |

**Рекомендация:** уточнить у заказчика, используется ли уже готовый Telegram-бот/модуль
поиска TourVisor — чтобы переиспользовать поиск и подписки, а нашу разработку
сфокусировать на AI-диалоге, визах и интеграции с канбаном.
