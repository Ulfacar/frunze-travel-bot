# Рейсы в карточке тура и ссылка tourcart (просьба Гриши 02.10.2026)

## Что просили

Гриша прислал образец подборки, какую шлют туроператоры, и попросил, чтобы бот слал так
же — «ссылку как у TourVisor, шаблон скопировать, который отправляют операторы». Позже
уточнил механику: менеджеры собирают туры в **корзину** в кабинете TourVisor и жмут
**«создать короткую ссылку»** → `tourcart.ru/?tvcard=qlc4ih`.

## Что оказалось на самом деле

Сверка образца с тем, что бот уже отправляет (живое сообщение с прода, 02.10):

| Строка образца | У бота было |
|---|---|
| `🏠 SWISSOTEL … 5⭐️` | да |
| `✈️ Бишкек ➡️ Египет, Шарм-эль-Шейх` | да |
| `✈️ 29 окт, 06:30 - 10:00, Red Sea Airlines - 20кг` ×2 | **нет** |
| `📅 29 окт, 🌙 6нч` | да |
| `🛌 deluxe room aqua, 2взр` | да |
| `🍽 Ультра Все Вкл` | да |
| `🏷️ 2 431 usd` | да (плюс «за двоих») |
| `Подробнее здесь: <ссылка>` | да, своя `/t/<slug>` |

То есть формат и ссылка были с 11.08. Не хватало ровно двух строк перелёта.
Ссылку клиенты открывают: **137 подборок, 111 открыты (81%), 289 просмотров.**

## Рейсы — сделано (`596ae70`, флаг OFF)

Разведка `scripts/tourvisor_flights_probe.py` на проде 02.10:

* в поисковой выдаче (`result.php`) рейсов нет — подтверждена разведка 11.08;
* `actualize.php` отвечает за 0.1 с, рейсов тоже не отдаёт, но даёт `detailavailable: 1`;
* **`actdetail.php?tourid=…` отдаёт всё**: `departure.time`, `arrival.time`,
  `company.name` («Pegasus Airlines»), `baggage` (20), `carryOn` («8 кг»), номер рейса.
  «+1» для ночного прилёта шлюз проставляет **сам** внутри времени («06:05 +1») — своего
  вычисления дат не делаем, иначе разойдёмся с оператором на часовых поясах.

**Цена, замеренная на проде:** один тур — 12 с, пять параллельно — 18–22 с, повтор того же
тура такой же медленный (шлюз не кэширует). Против 4 с на весь нынешний подбор. Риск
назван владельцу: в WhatsApp долгая тишина читается как «бот завис». Решение принято им —
полная карточка, флаг `tour_flights_enabled` с дефолтом OFF оставляет откат мгновенным.

Замер на живых данных (одноразовый контейнер, прод не трогали): весь ход **15.2 с**,
рейсы получены по 5 турам из 5.

## Ссылка `tourcart.ru` — BLOCKED на ответе TourVisor

`tourcart.ru` — сервис самого TourVisor (страница подтягивает `tourvisor.ru/module/init.js`
и `tourvisor.ru/img/logo-cart.svg`). Из нашего кода такую ссылку создать **нельзя**:

| Что проверено | Результат |
|---|---|
| `basket.php`, `tvcard.php`, `card.php`, `tourcart.php`, `shorturl.php`, `shortlink.php`, `link.php`, `createlink.php`, `offer.php`, `selection.php`, `share.php` | **404** — методов нет |
| `cart.php` | живой, но `{"success":0,"mess":"Client Zero"}` на **любые** параметры: `tourid`, `action=add/list/create/shortlink/getlink`, `clientid`, `client`, `operation`, `cart=new` — ответ не меняется |
| `api.tourvisor.ru` (новый REST) | `<html></html>` — SPA-заглушка; JWT-токена в `prod.env` нет (присылали 14.07, в прод не заводили, скоуп был только `search`) |
| документация `tourvisor.ru/xml/` | **403** с нашего сервера (гео-блок: VPS в Германии) |

Дальше подбирать параметры — гадание: для создания карточки всё равно нужна авторизация
кабинета агентства. Вопрос уходит в поддержку TourVisor (§ ниже).
