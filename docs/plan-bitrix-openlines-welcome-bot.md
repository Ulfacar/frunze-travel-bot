# План: бот в Bitrix Открытые линии (welcome-bot) для виз

**Дата:** 14.07.2026 · Цель: Bitrix = источник правды. Бот отвечает ПРЯМО в чате Открытой
линии (девочки видят), при перехвате оператором — замолкает. Пилот на визах (GetVisa).

## Что выяснено по порталу getvisakg.bitrix24.kz (через REST-вебхук)
- WhatsApp заведён в Bitrix через **Wappi → Открытые линии**. Визовые линии:
  **21 и 27 «WhatsApp Wappi: GetVisa»** (обе ACTIVE=Y, QUEUE_TYPE=evenly). Туры — 23/25.
- Ни на одной линии бот не подключён: `WELCOME_BOT_ENABLE=N`, `WELCOME_BOT_ID=0`.
- Механика линий: `WELCOME_BOT_JOIN=always` (бот входит в каждый чат),
  `WELCOME_BOT_LEFT=queue` (когда бот «уходит» — чат уходит в очередь операторам). ← наш кейс.
- Уже зарегистрированные боты: Инфобот(5), BitrixGPT(76967), **Wazzup(97283)**,
  careteam(117585/7), **Call Followup Bot(143221)** — чей CallFollowupBot, уточнить у Алана.
- Наш код готов наполовину: `app/channels/bitrix_openlines.py` (BitrixOpenLinesAdapter:
  parse ONIMBOTMESSAGEADD, send через imbot.message.add) + `/webhook/bitrix` в app/main.py.
  На проде путь ВЫКЛЮЧЕН (0 событий; активен Wappi-direct /webhook/wappi=3330).
- Визовый WhatsApp-бот на Wappi-direct сейчас OFF → двойных ответов не будет, старт чистый.

## Архитектура решения
Регистрируем НАШ imbot и вешаем его welcome-ботом на ОДНУ визовую линию. Тогда:
1. Клиент пишет в WhatsApp → Wappi → Открытая линия → бот (imbot) получает `ONIMBOTMESSAGEADD`
   на `/webhook/bitrix` → бот отвечает `imbot.message.add` → **видно в чате линии** + уходит
   клиенту через Wappi-коннектор.
2. Девочка перехватывает (пишет в чат / берёт в работу) → бот **замолкает** (handoff),
   чат уходит в очередь операторов (`WELCOME_BOT_LEFT=queue`).
3. Откат в 1 клик: `WELCOME_BOT_ENABLE=N` — бот мгновенно снят с линии.
