# Сценарий демо бота — что писать, чтобы красиво показать флоу

> Цель: за 5–7 минут показать, что бот встречает, квалифицирует по-человечески, даёт факты,
> не обещает лишнего и ведёт в офис/к менеджеру — плюс контроль менеджера (перехват, kill-switch).

## Перед демо (чек-лист)
- [ ] Баланс OpenRouter пополнен (иначе AI-ответы упрутся в фолбэк).
- [ ] `/admin/system` → `bots_enabled = ON`.
- [ ] Открыта админка `/admin` на втором экране — показать карточки/канбан вживую.
- [ ] Под рукой kill-switch: если диалог пойдёт не так — `bots_enabled = OFF` или перехват.

> ✅ TourVisor РАБОТАЕТ (проверено на проде 30.06: живые отели с ценами). Туры — полноценное
> демо с карточками. Визы тоже работают целиком. Билеты — сбор + передача менеджеру.

---

## 1. ГЕРОЙ: Визы (GetVisa, Медина) — полный флоу

Пиши боту по одной реплике, давай ему ответить:

1. `Здравствуйте, можно узнать про визу в США?`
   → представляется Мединой (личный визовый эксперт, 7 лет, 6000+ кейсов), спрашивает имя.
2. `Меня зовут Айбек`
   → тепло, спрашивает страну / начинает опросник.
3. `США, виза туристическая`
   → ведёт опросник по одному: возраст → семья → работа → поездки за 5 лет → отказы.
   Отвечай коротко на каждый (напр. `30 лет`, `женат`, `ИП`, `Турция, ОАЭ`, `отказов не было`).
4. `а какие шансы?`
   → **НЕ называет процент и не обещает визу**, говорит, что грамотная анкета и подготовка
   решают многое, и ведёт на консультацию. (Это и есть ключевой guardrail — показать клиенту.)
5. `сколько стоит?`
   → называет официальный прайс (США 250$ + консульский 185$), без депозитов; «итог подтвердит
   менеджер». 
6. `давайте` / `как записаться?`
   → приглашает в офис/онлайн (адрес GetVisa, почта для документов) → в админке карточка
   уезжает в «В офис / У менеджера».

**Что подсветить заказчику:** человеческий тон Медины, опросник как у реальных менеджеров,
честность без обещаний, и что всё это видно в админ-панели в реальном времени.

---

## 2. FAQ без LLM (мгновенно, даже при нуле на балансе)

Покажи, что частые вопросы отвечаются детерминированно (экономия + контроль из админки):
- `во сколько вы работаете?` → часы Frunze + GetVisa.
- `какой у вас адрес?` → адрес офиса.
- `сколько стоит виза в Китай?` → 300$ (инд.) / 200$ (групп.).

Затем открой `/admin/faq` → покажи, что менеджер сам правит эти ответы без программиста.

---

## 3. Идентичность («не палится, что бот»)

- `ты бот?` или `я с роботом говорю?`
  → не подтверждает и не отрицает, мягко возвращает к делу: «Я Медина, ваш визовый эксперт,
  давайте помогу с визой…». (Показать, что выполнено требование «без раскрытия AI».)

---

## 4. Контроль менеджера (перехват + kill-switch)

В админке на активной карточке:
1. Нажми **«Перехватить»** → бот замолкает; ответь клиенту сам из панели (показать ответ
   со статусом доставки).
2. Нажми **«Вернуть боту»** → бот снова в деле.
3. (Опционально) `/admin/system` → `bots_enabled = OFF` → бот молчит во всех чатах, входящие
   всё равно видны в панели → включить обратно. Это страховка на живом потоке.

---

## 5. Туры / Билеты (сбор + передача)

Покажи коротко, что воронки есть и собирают правильно:

**Туры:** `хочу тур в Турцию на двоих в августе` → Сезим собирает (направление → люди → даты →
бюджет) → **показывает живые отели с ценами из TourVisor** → бронь / менеджер.

**Билеты:** `нужны билеты Бишкек–Москва` → маршрут → даты туда/обратно → пассажиры → передаёт
менеджеру (живые тарифы подбирает человек).

---

## Если что-то пойдёт не так на демо
- Странный ответ → перехват из админки, ведёшь руками; диалог сохрани — поправим в связке.
- Совсем плохо → `bots_enabled = OFF`, демо продолжаешь в режиме «менеджер + панель».
