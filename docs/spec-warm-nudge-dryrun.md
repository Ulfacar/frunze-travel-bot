# СПЕКА для Codex — автодожим тёплых 🟡 (dry-run first)

Автор: Claude (планирует + ревьюит). Режим Веном. ⚠️ Единственная фича, где бот САМ пишет
живым клиентам — поэтому строго dry-run на старте (Winston настоял).

## Зачем
🟡-тёплые (интересовался, но не готов) остывают, если менеджер не вернулся. Инфра автодожима
уже есть (`app/core/followup.py`, планировщик, флаг `followup_enabled`, «тихие часы»), но она
шлёт общий пинг. Нужен персональный нудж из контекста диалога — и сперва без отправки.

## Почему dry-run
Авто-сообщение без ревью — репутационный риск, не только токены: бот может переврать бюджет из
`ai_summary`, предложить занятый тур. Первая неделя — генерируем ЧЕРНОВИК, показываем менеджеру в
панели, НЕ отправляем. После недели без нареканий — включаем автоотправку тумблером.

## Фаза A — dry-run (генерация черновика, без отправки)

### Данные
Колонки в `conversations` (миграция как у readiness):
- `nudge_draft` TEXT — сгенерированный текст дожима;
- `nudge_draft_at` TIMESTAMPTZ.

### Джоба `app/core/nudge.py` (планировщик, self-throttle ~час)
Флаги (в config, оба OFF по умолчанию):
- `nudge_draft_enabled: bool = False` — генерировать черновики;
- `nudge_autosend_enabled: bool = False` — реально отправлять (Фаза B).

Отбор кандидатов (чистая `_candidates`, тестируемо): `readiness_tier == "warm"` И
`last_sender != "client"` (мяч не у нас) И застой 24–72ч (не свежий, не совсем мёртвый) И
`nudge_draft` пуст И не в «тихие часы» (переиспользовать `followup.is_quiet_hour`) И
`followup_sent` == False (не дожимали). Кап `nudge_max_per_run` (напр. 15). Бюджет-гард
`llm_available()`.

Генерация (Haiku, `chat(model=llm_model_cheap, tools=[])`): system — «сгенерируй ОДНО короткое
вежливое сообщение-возврат от лица {persona} по контексту; не выдумывай цены/наличие; один вопрос
в конце; ≤300 симв». Вход — `ai_summary` + `qualification` (НЕ вся история — экономия). Пишем в
`nudge_draft` через `update_meta`.

### Показ в панели
В карточке диалога (`_conversation.html`) блок «Черновик дожима (ИИ)»: текст + кнопки
**«Отправить»** (`POST /admin/conversation/{uid}/nudge/send` — шлёт через outbound, ставит
`followup_sent=True`, чистит draft, аудит) и **«Убрать»** (чистит draft). Никакой автоотправки.

## Фаза B — автоотправка (только после недели dry-run и явного go)
Джоба при `nudge_autosend_enabled` шлёт `nudge_draft` сама (через `outbound`, как followup),
`followup_sent=True`, «тихие часы», один раз на диалог. Оставить возможность быстрого отката
тумблером `nudge_autosend_enabled=false`.

## Гварды
- Оба флага OFF по умолчанию → ноль стоимости и ноль отправок, пока явно не включат.
- Отправка — только WhatsApp-каналы (как followup), не Telegram-песочница.
- Один нудж на диалог (`followup_sent`), «тихие часы» Бишкека соблюдать.
- НЕ дожимать 🔴green (там менеджер) и ⚫noise (мёртвые).

## Тесты
- `_candidates`: warm+застой+мяч-не-у-нас → кандидат; green/noise/свежий/уже-дожатый/тихие-часы → пропуск.
- `run()` (мок chat): при `nudge_draft_enabled` пишет `nudge_draft`; при OFF — no-op.
- `POST /nudge/send`: шлёт, ставит followup_sent, чистит draft, скоуп-гард 404 на чужой.
- Фаза B автоотправка — тест с мок outbound за флагом.

## Деплой
Файлами + миграция (idempotent), флаги в `prod.env` держать OFF; включать `nudge_draft_enabled`
после ревью, `nudge_autosend_enabled` — только после недели наблюдения. codex-reviewer перед деплоем.
