```powershell
python -X utf8 scripts/build_kg_search_corpus.py --check
python -X utf8 scripts/build_kg_search_corpus.py --check --pdf "..\Kyrgyzstan-visa-knowledge-base-v1.1.pdf"
python -X utf8 scripts/build_kg_search_corpus.py --output runs/kg-search-corpus.json
python -m pytest tests/test_kg_search_corpus.py -q
```

`--check` ничего не создаёт. Сборка создаёт только отсутствующий файл; при существующем
результате проверяет равенство байтов и не переписывает его. Изменённый результат, иной
источник, повреждённые таблицы/ограждения кода отклоняются. При ошибке дисковой записи может
остаться неполный новый файл: следующий запуск его не перезапишет; используйте новый путь
после устранения причины. Для следующей версии нужны отдельные проверенные lock и каталог.
Модуль использует только стандартную библиотеку Python; сеть, конфигурация приложения и БД
не нужны. Опция `--pdf` проверяет идентичность файла, а не правильность конверсии его текста.

## Правила разбиения и метаданные

Включены только блоки **1–2, 5–13, 15–17**, как предписано в PDF. Промпт, JSON Б.3, YAML Б.5,
отдельные CRM-блоки 14/18/19 и служебное приложение конвертера не включаются.
Разделы выделяются по H2. При длине раздела больше 6000 символов допускается разбиение
по существующим H3; каждый дочерний фрагмент получает родительское введение и условия.
Введение блока сохраняется отдельным фрагментом `.0` и добавляется в контекст разделов.
`raw_text` выбранных диапазонов покрывает исходный текст ровно один раз;
`context_text` намеренно повторяет введение. Для поиска предназначен `text`, их соединение.

Таблица или fenced block всегда целиком принадлежит одному исходному диапазону.
Пять фрагментов остаются длиннее порога: `KG.KB.1.2`, `KG.KB.1.3`, `KG.KB.2.2`,
`KG.KB.7.0`, `KG.KB.17.0`. Они помечены `oversized`, текст не обрезан. Будущий индексатор
должен явно обработать ограничения модели; молчаливое усечение неприемлемо.

Каждый фрагмент содержит ID, блок, раздел/заголовок, версию, дату источника, хеши, точные
строки производного Markdown, ссылки SRC и метки ПРОВЕРИТЬ/ПРАКТИКА/РЕШЕНИЕ.
Метки считаются вместе с родительским контекстом: verify 24, practice 24, decision 10
фрагментов; категории пересекаются. `pdf_pages_from_markers` извлекается только из меток
конверсии и не заменяет независимую постраничную сверку.

Дата `2026-10-02` имеет `date_basis=source_claim`, не означает подтверждённую актуальность.
**Все фрагменты draft, may_quote=false, publication_approved=false; retrieval_connected=false.**
Эти поля описывают артефакт. Будущая интеграция должна обеспечивать запрет публикации на
сервере; наличие полей в JSON само по себе не является механизмом разграничения доступа.
