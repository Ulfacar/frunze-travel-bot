# E6-21 — ответы по утверждённым источникам

Локальный внутренний путь H03: `/admin/kg-entry/answers`, ссылка из поиска по PDF.
Существующие ограничения полного администратора, рабочего дня и выключенного
по умолчанию KG-пилота сохраняются. Выбор — до трёх точных кодов правил; язык RU/EN.

Каждый запрос заново читает действующую публикацию, проверяет её журнал, проекцию,
версию, серверную политику и актуальные подтверждения отдельных правил. Ответ
показывает тип правила, все поля структурированного значения, исходный фрагмент
при наличии, источник, страницу, раздел и версию. Для регистрации страна из
канонического кода указана отдельно. Контрольные суммы доступны в раскрываемой
части. Значения из источника не превращаются в решение о конкретном человеке,
расчёт конечной цены или календарной даты.

Без действующей публикации либо при отзыве, истечении срока, изменении основания,
политики или нарушении целостности выдаётся явное требование проверки специалиста.
При смешанном запросе подтверждённые сведения и неотвеченная часть разделены.
Неизвестная форма, неполные условия, числовой параметр без основания/границы счёта,
неопределённое множество «все остальные», черновой каталог дополнительных условий
и шаблон с переменными также требуют специалиста. Автоматического перевода текста
источника нет; шаблон доступен только на утверждённом языке.

Текст источника отображается буквально с HTML-экранированием и не исполняется.
Этот экран не загружает внешние скрипты/шрифты; работает без JavaScript.
`Cache-Control: no-store` и `Referrer-Policy: no-referrer` применяются к результату.

Путь только читает данные. Он не отправляет клиентское сообщение, не создаёт
карточку передачи специалисту и не подключает свободный клиентский диалог.
Согласование реальных источников, C05/H02 и запуск остаются отдельной работой.
Все положительные проверки используют искусственные источники и полномочия.
Реальные 208 единиц знаний этим изменением не утверждаются.

Возврат к прежнему состоянию — убрать новый модуль/маршрут и ссылку; миграций и
новых таблиц нет. Источники, подтверждения, публикации и дела не изменяются чтением.
Точные результаты, версии и границы независимых проверок записаны в task/handoff
E6-21 и соответствующих файлах `ai/reviews/`.
