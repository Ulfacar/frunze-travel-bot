# 🃏 Шпаргалка демо — что говорить у каждого экрана

## Открытие (одна фраза)
«Это одна система с двумя сторонами: **бот** общается с клиентами в WhatsApp/Telegram как живой
менеджер, а в **админ-панели** менеджеры всё видят и в любой момент могут вмешаться. Бот снимает
рутину первого контакта 24/7 и отдаёт менеджеру уже **тёплого, опрошенного клиента**.»

---

## Часть 1 — Бот (с телефона, пиши вживую)

**Визы (Медина):** `можно про визу в США?`
→ встречает как эксперт → опрашивает (страна, возраст, семья, работа, поездки, отказы) →
на `какие шансы?` **не обещает % и визу**, ведёт на консультацию → на `сколько стоит?` называет
прайс → приглашает в офис.
> Скажи: «вопросы и тон — по реальным диалогам ваших менеджеров».

**Туры (Сезим):** `хочу тур в Турцию на двоих в августе`
→ собирает (направление → люди → даты → бюджет) → **показывает живые отели с ценами** (TourVisor).
> Скажи: «цены живые, тянутся из TourVisor в реальном времени».

**FAQ (мгновенно):** `во сколько работаете?` / `какой адрес?`
→ моментальный факт без задержки. Скажи: «частые вопросы — без ожидания».

**Проверка «живости»:** `ты бот?` → не палится, мягко возвращает к делу.

---

## Часть 2 — Админ-панель (`frunzetravel.kg/admin`, открывается и с телефона)

1. **Доска (Визы/Туры/Билеты)** → «менеджер видит всех клиентов по стадиям; кто ждёт ответа —
   карточка подсвечена».
2. **Открыл карточку** → «вся переписка + **ИИ-бриф**: кто клиент, что хочет, следующий шаг».
3. **«Перехватить» → ответ из панели** → «в любой момент человек забирает диалог — **бот сразу
   замолкает**, не говорит поверх менеджера». Покажи статус доставки ✓✓.
4. **`/admin/faq`** → «готовые ответы менеджер правит сам, без программиста».
5. **`/admin/analytics`** → «сколько бот закрыл сам, исходы, время ответа» (если спросят про цифры).

---

## 🎯 Главный аргумент (повтори в конце)
«Бот **не заменяет** менеджера — он отсеивает рутину и приводит готового лида. Менеджер
подключается в один клик и работает с тёплым клиентом, а не с холодным номером.»
