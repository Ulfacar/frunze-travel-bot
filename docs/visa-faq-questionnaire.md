# Опросник для менеджеров по визам — наполнение FAQ бота

Цель: собрать канонические ответы на частые вопросы клиентов, чтобы **виза-бот отвечал по FAQ без обращения к LLM** (экономия токенов + контроль формулировок). Заполняйте кратко, «как отвечаете клиенту в чате». Один вопрос — один короткий ответ.

Правила ответов (напоминание политики):
- Называем **официальный прайс** (напр. 250$/100€ и т.д.), без скидок/депозитов/процентов.
- **Никаких гарантий одобрения.**
- По «нашим» странам — консультируем сами (позитивно, без обещаний); по «чужим» (напр. Бразилия) — сразу к менеджеру.
- Тон — как у Сезим/Медины, лаконично.

---

### Как это попадёт в бота
Каждая пара «вопрос → ответ» станет FAQ-правилом (матч по ключевым словам). Заполненный опросник верните — оформим в сиды FAQ и зальём, чтобы бот отвечал на эти вопросы мгновенно и без расхода LLM. Вопросы, требующие индивидуальной оценки (сложные кейсы, чужие страны), FAQ **не** закрывает — они уходят менеджеру.
