# Опрос сотрудников и решения владельцев

Приложение к [ТЗ](../spec-crm-frunze-getvisa-2026-10-03.md), разделы 7, 8, 16 и 20. Дата: 03.10.2026. Известные процессы выписаны из предоставленной транскрипции; предлагаемые детали помечены. Ответы ниже не считаются полученными.

## 1 Сообщение сотрудникам, готовое к отправке Аланом

Коллеги, готовим нашу CRM, чтобы после заключения договора было видно, что уже сделано, кто отвечает и какой следующий шаг. Посмотрите ниже маршрут своих продуктов: подтвердите его или поправьте. Для каждого шага нужны действие, ответственный, документы, срок, признак завершения и возможные сложности. Особенно важны случаи отказа, переноса, неполной оплаты и отсутствия ответа клиента/партнёра.

Пришлите действующие опросники и чек-листы без данных клиентов. Добавьте продукты, которых нет в списке. Можно ответить голосом: спорные места расшифровки уточним. Укажите, какие напоминания нужны вам и какие сообщения допустимо отправлять клиенту автоматически. Дата ответа и конкретный сотрудник назначаются Аланом.

## 3 Карточка ответа по продукту

Скопировать один экземпляр на продукт. Поле «не применяется» разрешено с пояснением; пустота означает «ответ не получен».

| Поле | Ответ сотрудника |
|---|---|
| Продукт, страна/вариант | Не заполнено |
| Сотрудник, роль, дата | Не заполнено |
| Когда начинается работа после продажи | Не заполнено |
| Что доказывает заключение договора | Не заполнено |
| Шаг 1: входной факт → действие → подтверждённый результат | Не заполнено |
| Следующие шаги в таком же формате | Не заполнено |
| Кто отвечает за каждый шаг и кто замещает | Не заполнено |
| Какие шаги идут параллельно | Не заполнено |
| Обязательные/условные документы, кто проверяет | Не заполнено |
| Обычное ожидание и настоящий крайний срок; источник каждого | Не заполнено |
| Оплата: цена, предоплата, остаток, расходы/платежи партнёру | Не заполнено |
| Отказ, перенос, переподбор, возврат, потеря связи | Не заполнено |
| Напоминания сотруднику: событие, смещение, отмена, эскалация | Не заполнено |
| Сообщения клиенту: текст/ссылка, момент, автоматом или после проверки | Не заполнено |
| Как подтверждается завершение и выдача документов | Не заполнено |
| Шаблоны/обезличенный пример | Не заполнено |
| Что сейчас неудобно и сколько занимает фиксация действия | Не заполнено |

Для каждого шага использовать строку: код; название; входные данные; действие; ответственный; результат; срок и его источник; документы; задачи; что делать при сбое. Из ответа разработчик делает версию процесса и показывает её сотруднику на одном примере. Сотрудник подтверждает смысл, Алан — включаемый объём.

## 5 Форма фиксации решения

Каждая запись: ID; вопрос; точный ответ; продукты/направления; ограничения; дата начала/окончания; утвердивший; дата подтверждения; ссылка на сообщение/документ; затронутые требования/задачи; исполнитель внесения; версия после изменения. Для денежных правил дополнительно цена/валюта/единица и что включено. Историю прошлых решений сохранять.

Статусы: НУЖЕН ОТВЕТ → НА СОГЛАСОВАНИИ → УТВЕРЖДЕНО / ОТКЛОНЕНО; ЗАМЕНЕНО для старой версии. Ячейка «утвердивший» и дата без точного текста ответа недостаточны. При изменении затронутых условий задача возвращается на проверку, а старые факты остаются в истории.
