# План задач по ТЗ CRM

03.10.2026. Источник — [ТЗ](../spec-crm-frunze-getvisa-2026-10-03.md). 35 задач; все статусы НЕ НАЧАТО. Классы риска относятся к будущей реализации. Для переноса реальных данных применяется CRITICAL даже при STANDARD у подготовительного шага. Зависимости — логический порядок, а не запрет параллельной подготовки. Список решений ограничивает включение затронутой функции; синтетическая разработка доступна раньше.

Оценки остаются на уровне этапов из раздела 18 ТЗ: R1 15–22 рабочих дня; R2 3–5 дней разработки плюс пилот; R3 10–16 дней после основы; E7 — 2–4 дня на прототип выбранной функции, выпуск отдельно. В план не включено ожидание внешних ответов и ревью. После E0 оценку пересчитать, календарные даты и персональных исполнителей назначить отдельно.

## Правила постановки

Задача готова к началу, когда доступны исходные требования, разобраны зависимости и определён способ проверки. Готова к завершению — когда выполнен результат, приложены доказательства, пройдено ревью по классу и обновлена точка продолжения. Приложение Word/таблица с планом не означают выполнения этих условий.

Точный состав блокеров: опросник можно разработать на синтетике до DEC-06; почту можно заменить ручным вводом до DEC-03; неутверждённый продукт остаётся черновиком; отключение Bitrix ждёт собственного решения. В E6-04 почтовая автоматика E6-03 обязательна только если включена в состав пилота — ручной подтверждённый ввод даёт проверяемый путь раньше.
