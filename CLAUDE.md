Этот файл Claude Code подхватывает автоматически на любом устройстве. Он заменяет
локальную память (она не переезжает между машинами) и держит то, что **не выводится

## 1. Что это

AI-агент-продавец для турагентства в Бишкеке. Принимает клиента в WhatsApp/Telegram,
квалифицирует, подбирает туры через TourVisor, отвечает по визам, передаёт «тёплого»
менеджеру и зеркалит всё в Bitrix24.

**Два бренда, один код:**
- **Frunze Travel** — туры и авиабилеты (номер +996707660009, профиль Wappi `FrunzeTravel2`)
- **GetVisa** — визы (номер +996706660009, профиль Wappi `GetVisa`)

Бот **в боевой эксплуатации с 01.07.2026**. Считать реальные диалоги только с этой даты —
всё, что раньше, это обкатка с выключениями.

**Люди:** Алан (`Ulfacar`, arialvhs@gmail.com) — ведёт проект, с ним и разговариваем.
Даулет — владелец бизнеса и заказчик по турам. Гриша — заказчик по визам (GetVisa).

## 2. Как работать с Аланом (протокол, важнее всего остального)

1. **Диагностику даю сразу**, не спрашивая разрешения посмотреть.
2. **Чиню целиком**, а не по кусочку — но **на прод выкатываю только по прямому слову Алана**.
   Само по себе «почини» деплой не разрешает.
3. **Всё, что меняет поведение для клиента, включается флагом, и флаг по умолчанию OFF.**
   Выкатили код — поведение не изменилось; включаем отдельным решением.
4. **В отчёте — измеренные числа, а не «стало лучше»**. Если не мерил — так и говорю.
5. **Сверяю диф, а не отчёт агента.** Был случай: отчёт заявил предохранители, которых в
   коде не было. Перед любым прод-действием читать диф/хеш.
6. Язык — русский, неформальный. Готовые тексты и решения ценятся выше вариантов на выбор.
7. На пересланные скриншоты переписки — сначала **разбор ситуации**, готовый текст ответа
   одной строкой в конце, а не вместо разбора.

Рабочий процесс разработки — **«Веном v2»**: гейт (критерии приёмки) пишется ДО работы и
исполнителем не правится, между фазами проверяет код `scripts/prod_traps_check.py`, ревью
идёт по диффу. Док: `docs/venom-v2.md`, скилл `/venom`. Триггеры: «режим Веном», «venom».

## 4. Прод и деплой

- Сервер: **62.171.185.155** (Ubuntu 24.04), SSH root по ключу. **Личный сервер Алана**,
  не заказчика. Путь `/root/frunze-travel`.
- Стек: docker compose — `app` (uvicorn на 127.0.0.1:8077) + postgres16 + redis7.
  Наружу смотрит **системный** nginx с сертификатом Let's Encrypt, домен `frunzetravel.kg`
  (плюс `app.frunzetravel.kg` под будущее Mini App).
- Docker — snap-версия: работает только из `/root` и не читает скрытые файлы,
  поэтому `.env` называется **`prod.env`** и он **вне git** (в нём боевые токены).

**Деплой — только через скрипт, руками compose не поднимать:**

```bash
# локально: отдать код на сервер (прод тянет НЕ с GitHub, а со своего bare-репо)
git push prod <branch>
# на сервере:
/root/frunze-travel/scripts/deploy_prod.sh <branch>     # дефолт: fix/tours-search-quality
/root/frunze-travel/scripts/rollback_prod.sh [commit]   # откат, если поломка логическая
```

`deploy_prod.sh` сам бэкапит prod.env, ждёт `/health` и **откатывается**, если приложение
не поднялось. Две ловушки, зашитые в скрипт и стоившие нам инцидентов:
1. `docker compose` без `--env-file prod.env` → `MANAGERS` пустой, логины менеджеров в
   панель отваливаются **молча**, при этом `/health` зелёный.
2. Без `-f docker-compose.vps.yml` контейнер лезет на 80/443, где уже сидит системный nginx.

**Гит-ремоуты:** `origin` = GitHub (`Ulfacar/frunze-travel-bot`), `prod` =
`ssh://root@62.171.185.155/root/frunze-repo.git`. Рабочая ветка — `fix/tours-search-quality`,
`main` держим на том же коммите.

## 5. Внешние системы и их подводные камни

**TourVisor** (подбор туров, XML API, аккаунт `frunzetravel@mail.ru`)
- Из Бишкека реально вылетают **Турция, ОАЭ, Мальдивы, Азербайджан**. По Египту, Таиланду,
  Кипру поиск честно возвращает **0 отелей** — и бот раньше врал, что дело в бюджете.
- Обязательны `childage1..N` — без возрастов детей выдача пустая.
- Валюта в ответах плавает (EUR), звёздность отелю LLM недоступна — берём из полей.
- Есть квота (`quota.py`); тариф меняли, «Горящие туры» — отдельный платный пакет.

**Wappi** (мост WhatsApp) — каналы регулярно отваливаются по QR и это **не видно по трафику**:
тишина не отличает мёртвый канал от тихого. Поэтому сторож v3 спрашивает у Wappi
**статус профиля**, а не считает молчание. Подписки платные, у GetVisa истекала 20.08.2026 —
проверить оплату.

**Bitrix24** (`getvisakg.bitrix24.kz`, inbound REST-вебхук; токен НЕ хранить в репо/памяти)
- **Два потока лидов, это корень жалобы «мы не видим бота»:** поток Wappi → Открытые линии
  (там сидят менеджеры) и поток нашего бота (лиды падали на служебный аккаунт 155383).
- Реплики бота попадают в чат Открытой линии только с параметром **`bot_id=external_api`**.
  Ответы менеджеров возвращаются через `outgoing_message_api`.
- ID менеджеров: Медина 96451, Элиза 110841, Адеми 155313, Айсина 155267.
- Разница поведения виз и туров = **тип очереди Открытой линии** (`evenly` против `all`).
- Портал молча съедает эмодзи и BBCode в карточках — это дефект портала, не наш.
- 🔴 **Продажи в CRM не заносятся с 13.06** → конверсия объективно не меряется. Любые
  выводы про «сколько продали» через Bitrix недостоверны: у таргетологов 158 продаж
  против 7 сделок в CRM.

**LLM** — OpenRouter, роутинг Haiku/Sonnet + кэш. Расход порядка **$17/мес**.

**STT (голосовые)** — OpenAI. Технически 100% успех, ~28 голосовых/день. Но **кыргызского
языка в модели нет**: 54% кыргызской речи — нечитаемая каша. Отсюда `stt_guard` — фильтр
доверия к расшифровке.

## 7. Бизнес-правила, которых нет в коде очевидно

- **Часы приёма:** разговаривать бот может в любой день, а **визит в офис назначать только
  пн–сб**. Это перекрывает «работаем ежедневно» из туровой анкеты — бот однажды записал
  клиента на воскресенье.
- **Визы:** бот называет официальный прайс (250$/100€ и т.д.). Депозиты, проценты и любые
  гарантии выдачи — **запрещены**. По «нашим» странам консультирует сам, по чужим
  (Бразилия и пр.) сразу отдаёт менеджеру.
- **Цены по турам** публикует только админ; клиенту — вилка как приманка в офис.
- **Ручное важнее бота:** менеджер перехватил диалог → бот замолкает (`intercept.py`, TTL).
- **Владение диалогом закреплённое**, перехват чужого запрещён (кроме админа).
- **Бот — ночной диспетчер, а не продавец.** Это рефрейм всей ценности: медиана ответа
  живого менеджера была 3 часа, 20% лидов приходят ночью.
- Бот знает сегодняшнюю дату — её инъектим в промпт каждый ход (без этого он гадал месяц).
